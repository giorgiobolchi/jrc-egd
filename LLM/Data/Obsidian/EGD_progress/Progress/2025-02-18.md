


- Simone's thoughts about "504 Gateway Time-out The server didn't respond in time." error:

	There are a couple of explanations for this, all related to the fact that these models run on JRC's servers and not OpenAI's ones, which are more powerful and super-optimized.
	
	First, it could just be that this is because it is your first time using it. There is a bunch of stuff that needs to get loaded when you access a model through the JRC local API for the first time. *I would run the same prompt a few more times and see if it still gives you the 504 error.* It stopped after the third time for me. Future prompts should go much faster.
	
	Second, these local models are slower, so it is going to take longer to get an answer. If it takes too long, the whole thing shuts down. Again, I would first just try to run it a few times. Otherwise, it might have to do with the amount of text you send, so then it is better to try and segment it across multiple calls.
